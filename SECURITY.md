# Segurança e privacidade / Security and privacy

Este repositório publica apenas dados e arquivos destinados à análise agregada. Nunca inclua dados identificáveis de pacientes, chaves privadas, tokens, credenciais ou arquivos de configuração de segredos.

For public deployment: keep medical/health data at an aggregate level, avoid uploading patient-level identifiers, and never commit API keys or Streamlit secrets.

Antes da publicação pública, revise os arquivos do repositório e as políticas aplicáveis à pesquisa e aos dados utilizados. Relatos de vulnerabilidade não devem expor informações sensíveis em issues públicos.
